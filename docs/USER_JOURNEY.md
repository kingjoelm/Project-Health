# User Journey

## First Open

Goal: The user feels understood, not evaluated.

Collect only information needed to create a useful starting plan:

- First name
- Age
- Height
- Current weight
- Goal
- Experience
- Available workout days
- Typical workout time
- Equipment or gym access
- Injuries or movement limitations
- Biggest current obstacle

## Daily Open

The Today screen should immediately show:

- Coach PH message
- Energy and sleep check-in
- Today's workout
- Full, short, minimum, and recovery choices
- Water
- One better food choice
- Yesterday's victory
- Momentum

## At the Gym

The user should know:

- Which exercise is next
- Sets and repetitions
- Last weight used
- A form reminder
- An alternative exercise
- How much remains

## After the Workout

Ask:

- How difficult was it?
- Any pain?
- What felt strong?
- Today's victory

Then provide one sentence from Coach PH.

## When a Workout Is Missed

Offer:

- Resume today's plan
- Short workout
- Five-minute walk
- Recovery
- Life Happened check-in

Never reset the user's identity or progress.

## Weekly Review

Show:

- Workouts completed
- Minimum days completed
- Water consistency
- Food honesty
- Strength or repetition progress
- Invisible progress
- One focus for next week
