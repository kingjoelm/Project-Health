# Project Health Vision

## Mission

Project Health helps people become healthier through small, sustainable improvements instead of perfection.

## Product Promise

Every time a user opens Project Health, the app should help them answer one question:

> What is the next best thing I can do today?

## What We Are Building

Project Health is a behavior-change coaching platform with fitness as its first use case.

It is not designed to shame users, punish missed days, or overwhelm people with data. It is designed to help users become more capable, more consistent, and more confident.

## Core Outcomes

Project Health should help users:

- Build realistic exercise habits.
- Improve food choices without demanding perfection.
- Recover from missed days without quitting.
- Notice progress beyond body weight.
- Build confidence through honest tracking and small victories.
- Receive coaching that adapts to real life.

## Product Standard

Before adding any feature, ask:

1. Does this help the user take a useful action?
2. Does this make the user feel more capable rather than more monitored?
3. Does this fit the Coach PH principles?
4. Can the feature work without guilt, fear, or unrealistic expectations?
