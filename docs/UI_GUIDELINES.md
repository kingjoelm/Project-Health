# UI Guidelines

## Design Goal

Project Health should feel calm, clear, and supportive.

## Navigation

Primary tabs:

- Today
- Workout
- Progress
- Profile

The most important action should be visible without opening a menu.

## Writing

- Use short sentences.
- Avoid judgmental labels.
- Use one recommendation at a time.
- Prefer action language.
- Avoid excessive exclamation marks.
- Never use red solely to shame incomplete behavior.

## Buttons

Primary actions should use direct labels:

- Start Full Workout
- Do Short Workout
- Protect the Habit for 5 Minutes
- Choose Recovery
- Log Today's Victory

Avoid vague labels such as Continue when a more specific label is possible.

## Accessibility

- Large tap targets
- Readable text
- Strong contrast
- No essential meaning communicated only through color
- Form labels must remain visible
- Mobile-first layouts
