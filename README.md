# Project Health v0.2

## New behavior-coaching features
- Full, short, minimum and recovery-day choices
- Five-minute walk timer
- "Next Better Choice" food coaching
- One fewer drink, slice/tortilla or second serving
- Honest logging without all-or-nothing language
- Offline-capable PWA foundation

## Upload to GitHub
Upload the CONTENTS of this folder into the repository root:
- index.html
- app.js
- manifest.webmanifest
- service-worker.js
- icons/
- data/
- exercise-images/

Do not upload the outer project-health-v0.2 folder as one nested folder if GitHub Pages or Cloudflare Pages should serve index.html from the repository root.
