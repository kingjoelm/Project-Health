# Project Health v0.3 — Coach PH Foundation + Gym Beta

This package contains:

- A mobile-first Project Health app that can be used at the gym today.
- Coach PH decision rules and philosophy.
- Full, short, minimum-day, and recovery workout modes.
- Daily check-in.
- Water, food, weight, workout, and victory tracking.
- Local browser storage.
- JSON backup export and import.
- Offline PWA support after deployment.
- Professional product documentation in `/docs`.

## Use Today

### Fastest method

1. Open `index.html` in a browser on a computer.
2. For phone use, upload the full folder to GitHub and enable GitHub Pages.
3. Open the GitHub Pages link on your phone.
4. Add it to the home screen.

## GitHub Pages

1. Upload all files and folders to the root of your `Project-Health` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/root`.
5. Save.
6. Wait for GitHub to provide the site address.

## Important

Data is stored locally in the browser used to open the app. Use **Progress → Export** and save the JSON backup in OneDrive.

## Gym Safety

Use controlled weights and stop any movement that causes sharp or concerning pain. This beta does not provide medical diagnosis.
