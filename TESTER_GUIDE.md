# Project Health v0.11 Tester Guide

## What to test

1. Create or select your profile.
2. Complete the daily readiness check.
3. Try at least one strength workout or custom program.
4. Track one walk, run, bike ride, or mobility session.
5. Log meals, water, weight, or a daily victory.
6. Try installing Project Health to your home screen.
7. Export a Tester Package after several days.
8. Send feedback for anything confusing, slow, broken, or missing.

## Data safety

This beta stores records in the browser on the tester's device. Export backups regularly. Clearing browser/site data may remove records.

## Location

Location is only requested when the tester explicitly chooses to save or check a workout place. The website does not continuously track location.

Automatic arrival notifications require a later native/mobile and cloud phase.

## Recommended private beta size

Start with 5–10 trusted testers using their own devices for one to two weeks.
